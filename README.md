# simple-landing-page

A Bootstrap landing page exercise with navigation, a hero section, service highlights, and testimonials.

[Repository](https://github.com/MirzaAlbab/simple-landing-page)

## Features

- Responsive Bootstrap 4 layout
- Workplace and gallery sections
- Local styles, images, and Bootstrap assets

## Technology

HTML, CSS, Bootstrap 4, JavaScript

## Getting started

Clone the repository and serve the root directory with a local static web server. For example, with Python 3:

```bash
git clone https://github.com/MirzaAlbab/simple-landing-page.git
cd simple-landing-page
```

```bash
python3 -m http.server 8000
```

Open [http://localhost:8000](http://localhost:8000). Keep the relative directory layout intact so styles, scripts, and images resolve correctly.

## Development and checks

Check page navigation, responsive layouts, browser console errors, and missing assets in a browser. No root automated test runner is configured.
